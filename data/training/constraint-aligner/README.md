# Correctness Aligner SFT Warmup Data Placeholder

Download the Diff-SQL HuggingFace dataset:

```text
https://huggingface.co/datasets/birdsql/Diff-SQL
```

Place the correctness-aligner SFT warmup parquet files here:

```text
train.parquet
dev.parquet
```

Source path in the HuggingFace dataset:

```text
correctness-aligner-training-dataset/train.parquet
correctness-aligner-training-dataset/dev.parquet
```

These files are for supervised warmup of the Correctness Aligner.
